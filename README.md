
# 🧬 Immunoassay Data Science & Biostatistical Portfolio

Welcome! I am an **Assay Development Scientist & Data Analytics Specialist** with a B.S. in Biology and an M.S. in Data Science. My work bridges the gap between wet-lab immunoassay development (**Siemens Chemiluminescent & Abbott Architect platforms**) and advanced biostatistical modeling.

This portfolio highlights my technical proficiency in **ELISA and immunoassay optimization**, **4PL/5PL weighted non-linear regression**, **CLSI guidelines (EP5-A3, EP06-A)**, and automated analysis pipelines built in **Python, R, and JMP** to drive diagnostic products to **FDA regulatory submission readiness**.

---

## 📂 Featured Projects

### 1. Automated 4PL / 5PL Non-Linear Regression for Immunoassays
* **Tech Stack:** `Python`, `SciPy`, `NumPy`, `Matplotlib`
* **Overview:** A custom Python script designed to process raw luminescence/absorbance data from ELISA and chemiluminescent assays, fitting standard curves using 4-parameter logistic (4PL) regression.
* **Impact:** Automates outlier detection, calculates back-fitted concentrations, and generates recovery curves to eliminate manual standardization bottlenecks.

### 2. CLSI-Guided Precision & Linearity Analysis Pipeline
* **Tech Stack:** `R`, `tidyverse`, `drc`
* **Overview:** An analytical pipeline implementing **CLSI EP5-A3 and EP06-A guidelines** to evaluate within-run and total precision, variance components, and linearity across multi-site diagnostic runs.
* **Impact:** Streamlines Design Verification & Validation (V&V) data analysis, reducing statistical processing time for cross-functional teams.
